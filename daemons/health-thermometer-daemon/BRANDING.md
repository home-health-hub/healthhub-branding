# Health thermometer branding

- Functional focus: Bluetooth health-temperature readings
- Representative device: manufacturer-neutral no-touch infrared forehead thermometer
- Complementary accent: coral (`#FF7A61`)
- Approved roles: README banner, dashboard application image, and navigation icon
- Launcher status: internal Health Hub function, not a separate operating-system launcher
- Current SVG classification: hybrid

Use the no-touch thermometer as a recognizable visual representative of the function, not as a compatibility claim or restriction. Keep the thermometer, Bluetooth mark, home-computing elements, and local-storage motif in the shared teal/aqua family. Reserve coral for infrared sensing, temperature emphasis, and the data path. Do not add manufacturer marks, arbitrary readings, people, or contact-thermometer imagery.
