# Organization avatar

The organization avatar is the shared identity for Home Health Hub and the only operating-system application launcher icon. The Health Hub launcher opens the main Hub login page.

- Application ID and icon basename: `org.homehealthhub.healthhub`
- Approved raster: `approved/organization-avatar.png`
- Current SVG classification: hybrid
- Linux exports: 16, 22, 24, 32, 48, 64, 96, 128, 256, and 512 pixels, plus scalable SVG
- Web exports: ICO, favicon PNG/SVG, Apple touch icon, 192/512 PWA icons, and maskable variants

Do not recolor this avatar with a daemon accent. Small exports must be inspected for clarity after regeneration.
